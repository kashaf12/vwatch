# Code of conduct

vwatch follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, criticise ideas rather than people, and keep discussions about the work.
Harassment, insults and personal attacks are not welcome in issues, pull requests, discussions or anywhere
else the project lives.

To report a problem, open a [private security advisory](https://github.com/kashaf12/vwatch/security/advisories/new)
(it reaches the maintainer only) or contact the maintainer through their GitHub profile. Reports are kept
confidential.
